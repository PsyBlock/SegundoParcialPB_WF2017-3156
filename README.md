## Descripcion del programa

Este proyecto consiste en el desarrollo de una aplicación de escritorio para la gestión de pedidos de una cafetería, utilizando C# y 
Windows Forms en el entorno de desarrollo Visual Studio.

El sistema permite registrar los pedidos de los clientes mediante una interfaz gráfica intuitiva y fácil de utilizar. Además, facilita la 
selección de productos del menú, el ingreso de cantidades y el cálculo automático del monto total a pagar.
